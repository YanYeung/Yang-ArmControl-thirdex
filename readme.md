# 机械臂控制扩展 (Arm Control Extension)

这是一个为 [Mind+](https://mindplus.cc/) 设计的图形化编程扩展，旨在简化机械臂的控制，支持通过串口（UART）控制机械臂执行动作组。

## 功能特性

- **初始化机械臂控制器**：自定义 TX 和 RX 引脚。
- **运行动作组**：指定动作组编号及运行次数。
- **停止动作组**：随时终止正在执行的动作组。

## 支持平台

该扩展支持以下主流开发板：

- **ESP32 系列**：掌控板、行空板K10



## 安装方法

1. 打开 Mind+。
2. 进入“扩展”中心。
3. 选择“用户库”，并搜索或粘贴此项目的 URL。
4. 加载扩展。

## 积木说明

### 1. 初始化机械臂
- **描述**：设置机械臂控制器的 TX 和 RX 引脚。
- **参数**：
  - `TX`: 发送引脚
  - `RX`: 接收引脚

### 2. 运行动作组
- **描述**：运行预设的动作组。
- **参数**：
  - `NUM`: 动作组编号 (0-230)
  - `TIMES`: 运行次数 (0-100)

### 3. 停止动作组
- **描述**：停止当前正在运行的动作组。
